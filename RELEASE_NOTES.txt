pgsavvy v0.11.4

  Release publication now requires a non-empty release-notes entry matching
  the pushed tag. Added validation tests and restored missing v0.11.3 notes.
  Application behavior is unchanged.

pgsavvy v0.11.3

  Clarified keybinding-prefix diagnostics with affected keys, actions, mode,
  scope, and binding origins. Shipped-default overlaps are informational;
  user-binding overlaps remain warnings. Informational diagnostics no longer
  trigger reload warnings. Custom-command shell text is omitted from diagnostics.
  Keybindings and timeout behavior are unchanged.

  Fixed the release-asset golden test to use GoReleaser's metadata tag.

pgsavvy v0.11.2

  Fixed startup warnings corrupting the terminal display. Diagnostics remain in
  session logs and are replayed after the TUI closes and restores the terminal.
  Keybindings are unchanged.

pgsavvy v0.11.1

  Refresh the screen when closing the connection manager or settings, even
  when replacement panels increase the window count. Modal transitions avoid
  duplicate refreshes, while ordinary editing keeps incremental rendering.

pgsavvy v0.11.0

  Copy complete query-error panels with y or yy after manually entering Results.
  Both commands copy the same sanitized text, including diagnostics beyond the
  visible viewport and the displayed SQL/caret excerpt. Existing grid yanks and
  query focus behavior remain unchanged.

pgsavvy v0.10.3

  Improved typing responsiveness in large SQL documents by rendering only
  visible text without syntax highlighting and disabling automatic completion
  scans. Manual completion and full-document editing, saving, and execution
  remain available.

pgsavvy v0.10.2

  Saved queries now open with <leader>H; <leader>h still opens query history.
  Fixed false missing-help warnings and made ? an explicit default binding.
  Saved Queries and History now display loaded rows on first open, without
  another keypress or tab switch.

pgsavvy v0.10.1

  Fixed editing, commits, streaming, navigation, query saving, exports, and
  Unicode rendering. Hardened credential handling and updated dependencies.

  Before downgrading, back up settings and use separate state/config directories;
  shared-state downgrades are unsupported. See docs/INSTALL.md.

pgsavvy v0.10.0

  Major UI performance improvements for long running queries where the UI is now separated from the query execution and results rendering. This allows for a more responsive experience when working with large datasets.

pgsavvy v0.9.1

  Fixed pasting in the edit cell.
  Cursor now lands on the operated range after delete/change operators
  (ciw, dw, dip, ...), matching vim semantics.
  Fixed cursor position after dd/yy/cc operators.

pgsavvy v0.9.0

  New file explorer modal for browsing, opening, and saving files.
  Open .sql files in the query editor with <leader>of.
  Save results from the export modal by selecting save type "File" and
  selecting a path (i).
